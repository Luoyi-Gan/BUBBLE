# C 题全题物理意义最终审计

**状态：** 等待 Q1–Q4 全部计算完成后执行。  
**性质：** 正式结果、论文结论与 result 文件的最终放行门槛。任何数值最优但不能解释为实际能量、设备动作或交易行为的结果均不得采用。

## 1. 全题共用的六项硬约束

| 审计维度 | 必须回答的问题 | 不通过的典型情形 |
| --- | --- | --- |
| 能量守恒 | 每个时段输入、输出、储能变化和弃置能量是否闭合 | 凭空产生/消失电能；平衡残差被忽略 |
| 单位与计量点 | 功率、能量、价格、SOC 与计量位置是否一致 | kW 直接与 kWh 相加；电池侧和母线侧变量混用 |
| 设备可行性 | 功率、容量、效率、SOC 和充放电状态是否符合设备物理边界 | 超额充放电、越界 SOC、将 90% 往返效率重复损耗 |
| 信息时序 | 每项决策在作出时是否只使用当时可获得的信息 | 日前计划读取未来实际负荷/光伏；把回测结果当作预测输入 |
| 市场/合同边界 | 购电、紧急购电、弃光、售电和计划结算是否均有题面或明确假设支撑 | 虚构售电收益；将已锁定购电计划免费撤销 |
| 跨时段边界 | 初值、日末状态、跨日传递和计算区间成本是否一致 | 用未来免费能量；不同对照采用不同初始 SOC 或核算区间 |

## 3. 最终执行流程

1. **事实—假设分离。** ACCT 将题面/附件直接给定、文献可支持的一般认识、本文假设、未考虑因素逐项标注。
2. **量纲审计。** 对每条目标与约束做单位检查；所有 10 分钟功率输入均确认已乘 \(1/6\) 转为能量。
3. **逐时段物理审计。** Cursor 导出每题最大能量平衡残差、SOC/功率越界数、同时充放电量、弃光与紧急购电记录。
4. **边界与反事实审计。** Codex 检查初始/终端 SOC、跨日传递、购电上限、外送权利和结算方式；使用无储能、完美信息或压力情景验证结论不依赖漏洞。
5. **解释审计。** FIN 对每个论文结论标明它对应的物理机制和证据边界，禁止把数值相关性写成未经验证的因果机制。
6. **队长签收。** 队长只在每个小问“物理含义通过 / 限制已写入论文 / 结果文件一致”三个条件同时满足时签收。

## 5. 一票否决项

- 任何结果依赖未来真实数据，却在论文中声称为日前或实时决策；
- 任何结果无法满足逐时段能量平衡、SOC/功率边界或设备效率定义；
- 任何成本优势来自未计费计划电、免费初始储能、虚构售电、未说明的弃电或不一致的比较区间；
- 任何表格数值无法从可复现输出回溯到对应的变量、单位和时间标签。
