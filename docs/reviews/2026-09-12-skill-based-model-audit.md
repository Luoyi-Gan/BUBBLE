## 1. 模型主线评价（这是真正的优势）

一条可贯穿全文的机理，符合 `cumcm-b-problem` 与 `cumcm-review` 致命项 11（禁止四问互不相关）：

```text
公共母线能量守恒 + 储能 SOC 转移
        → Q1 信息完全时的最优购电
        → Q2 预测误差下锁定 q、滚动补救
        → Q3 光伏预报刷新下调整 g、用 VoI 解释
        → Q4 电价也不再事先已知，只换信息集
```

统一目标始终是**实际购电成本**（普通电 + 紧急电，Q3/Q4-3 再加调整费）。这满足专家讲评里“决策题先定义统一指标”，也避开 AHP/熵权/TOPSIS 套娃（致命项 8）。

结构化简也符合 skill：正电价、无售电、有损耗 ⇒ 同时充放电被支配 ⇒ 主模型保持 LP，二元变量只作复核。这是“合理简化是优点”，不是偷懒。

验证已经超过“机械 ±5%”：Q1 效率/PCC/无储能；Q2 oracle 与 K 对照；Q3 因果 vs 代理、年末 A/B、M0/消融；Q4 信息集扰动。这是 `cumcm-modeling` 要的“针对性检验”，不是为灵敏度而灵敏度。

## 7. 按问：可写进论文的“为什么是这个模型”

**Q1** 输出是决策不是预测。附件 1 已给全日曲线，再做预报是答错题。LP 与能量守恒一一对应，独立 `linprog` 已复核。

**Q2** 难点是信息不完全 + 计划锁定。均值预报是 Level 0 时序基线；K-medoids 压缩历史残差是情景生成，不是“真实概率”。MPC 保证可执行。oracle 是对照不是下界（可行集包含未证）。

**Q3** 新信息是附件 3 的四次光伏，不是新物理。滚动 LP + 调整费进目标，使“不调整”始终可行，故不必人为阈值。VoI 是解释层。

**Q4** 新信息是附件 4 的实时价。在线 MAE 选窗口 = 滚动原点验证，符合 time-series skill 的“禁止打乱 K 折”。OLS 前缀修正 = Level 1 nowcast。三元残差避免 \(\mathbb E[p]\mathbb E[N]\) 拆开。主目标仍是实现成本。
