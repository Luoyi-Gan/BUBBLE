# C 题 Q2：紧急购电的题意、支配性与核查（FQ2-4）

## 证据属性

- **题面事实：** 供能不足部分按同一时段正常电价的 5 倍紧急购电。该倍数不需要外部引用，正式论文只引用 Q2 题面。
- **数学推导：** 若正常购电与紧急购电在同一母线、同一时段可相互替代，正常购电没有上限且能在已知确定性实现值后自由选择，那么正的紧急购电被正常购电严格支配。这是模型结构结论，不是文献事实。
- **信息结构：** 紧急购电要有现实含义，正常计划购电必须在不确定量实现前锁定，紧急购电只能在实现后补足偏差；或另有题面给定的正常购电容量/变更限制。当前 Q2 规格采用前一种两阶段解释。

## 数学推导

设时段 $t$ 的正常电价 $p_t>0$，正常计划购电 $g_t\ge0$，紧急购电 $u_t\ge0$，成本项为

\[
C_t=p_t g_t+5p_t u_t.
\]

在确定性给定日模型中，若 $g_t$ 与 $u_t$ 同时决策、进入同一能量平衡，且 $g_t$ 无上限，则对任意 $u_t>0$，取 $0<\varepsilon\le u_t$，构造

\[
g'_t=g_t+\varepsilon,\qquad u'_t=u_t-\varepsilon.
\]

总供能不变，所有与二者总和有关的约束仍满足，而成本变化为

\[
C'_t-C_t=p_t\varepsilon-5p_t\varepsilon=-4p_t\varepsilon<0.
\]

因此原解不可能最优，最优解通常有 $u_t=0$。这里的“通常”保留了数值容差，以及模型中可能存在不同母线、容量、时序锁定或其他约束的例外。

## 可直接写入论文的方法段落

题目规定供能不足时按正常电价的 5 倍紧急购电。为避免在同一确定性优化中由无上限正常购电严格支配紧急购电，本文将两类购电按决策时点区分：每日 0:00 基于当时可得历史信息和预测确定计划购电 $g_{D,t}$；实际负荷与光伏在时段 $t$ 到来后，固定既定 $g_{D,t}$，再由储能调节并以 $u_{D,t}$ 补足残余缺口。故 $u_{D,t}$ 表示预测偏差下的事后应急补购，而非与日初计划购电同时自由选择的廉价替代品。完全信息给定日求解仅作为离线下界，并应出现 $u_{D,t}\approx0$。

## 三组结果必须分开

| 名称 | 正常购电何时确定 | 实际曲线是否预知 | 紧急购电含义 | 可作何种结论 |
|---|---|---|---|---|
| 可执行滚动策略 | 每日 0:00 | 否 | 实现后补足计划偏差 | Q2 主结果候选 |
| 场景两阶段计划 | 日初、各场景共享 $g$ | 只知分布/历史场景 | 各场景补救变量 | 风险规划或日初计划模型 |
| 给定日完全信息基准 | 与当日实际值一起求解 | 是 | 被正常购电支配，通常为 0 | 仅作成本下界/上帝视角对照 |

## 代码与结果核查

- [ ] 计划变量 $g_{D,t}$ 在所有日初场景间共享，不能为每个场景各自重选。
- [ ] 实际回测固定日初的 $g_{D,t}$，再计算储能动作与 $u_{D,t}$。
- [ ] 逐时验证负荷平衡、$u_{D,t}\ge0$ 和紧急成本 $5p_tu_{D,t}$。
- [ ] 年度成本同时列计划购电费、紧急购电费和二者合计；CVaR/惩罚项不混入“实际电费”。
- [ ] 完全信息基准若出现明显正的 $u$，检查正常购电上限、不同母线、固定 $g$ 或代码错误；若均不存在，应视为异常。
- [ ] 主结果若全年 $u=0$，不能直接宣称“预测准确”或“系统无风险”；先检查是否误用了当天实际曲线、是否让 $g$ 事后调整、正常购电是否无上限且没有计划约束。

## Codex 复核结论

上述支配性证明在“同一时段、同一母线、正常购电无上限、二者同时根据确定性实现值决策、$p_t>0$”五项条件同时成立时有效；当前 Q2 两阶段/滚动信息结构通过在实现前固定 $g$ 使紧急购电成为有意义的补救变量。
