## 使用边界

- 题给参数、附件数据字段、页码、工作表名和单位，仍须以赛题原件逐项核对；当前“待核”标注不得写成已确认事实。
- 外部文献只支持方法合理性与适用边界，不能替代题目给值，也不能证明本项目自定参数或策略最优。
- 尚未签收的项目保持为假设/局限，不应据此重跑或改动 Q2 主结果。
