# C 题 · 小问 2 建模规格

> Codex 起草 → AI 队长确认 → Cursor 实现。确认后在文首改状态为 **已确认** 并填日期。

**状态：** 草稿  
**题目 / 小问：** C 题 Q2：预测误差下的日前计划购电与紧急购电控制  
**队长确认：** —

## 1. 目标

在每天 0:00，利用当日之前可获得的历史负荷与光伏数据制定 144 个时段的计划购电量。实际负荷、光伏偏离预测时，利用储能吸收偏差；若仍供电不足，则紧急购电，价格为该时段计划购电价的 5 倍。

成功标准：在 2025.2.1–12.31 的滚动回测中，无供电缺口；生成题目要求的计划购电、充放电、紧急购电结果；所有预测严格不用当天及未来真实数据。

## 2. 假设与符号

沿用 Q1 的 \(\Delta,L,P,p,g,c,d,E,s\) 定义。对日期 \(D\)，\(\widehat L_{D,t}\)、\(\widehat P_{D,t}\) 是在 \(D\) 日 0:00 可得的预测；\(u_{D,t}\) 是紧急购电量。

| 符号 | 含义 | 单位 / 取值范围 |
|---|---|---|
| \(\omega\in\Omega_D\) | 由历史日构造的负荷-光伏偏差场景 | 场景索引 |
| \(L_{D,t}^\omega,P_{D,t}^\omega\) | 场景实际负荷、光伏能量 | kWh |
| \(g_{D,t}\) | 0:00 锁定的计划购电量 | kWh，所有场景共享 |
| \(c^\omega_{D,t},d^\omega_{D,t},E^\omega_{D,t}\) | 实际运行时的储能补救动作 | kWh |
| \(u^\omega_{D,t}\) | 紧急购电量 | kWh，\(\ge0\) |

必要假设：

1. 计划购电量按普通电价结算，即使实际时段有剩余也不能退回或售回外网。
2. 负荷与光伏的实际值在各时段到达时才可观测；紧急购电是最后补救手段。
3. Q2 未要求每日首末 SOC 相等，应保持跨日 SOC 连续。为避免每天末端无理由耗尽电池，日前模型使用可解释的终端安全储能目标 \(R_D\)，并在回测中报告其影响。

## 3. 数据

- 来源：`C题/附件/附件1.xlsx`（固定日内价格）；`C题/附件/附件2.xlsx`（`小区负载`、`光伏发电实际功率`）。
- 回测区间：2025.2.1–12.31；2025.1.1–1.31 仅用于冷启动训练。
- 预处理：宽表转为 `date,time,load_kw,pv_kw` 长表；功率乘 \(\Delta\)；每日完整性检查 144 时段。
- 防泄漏规则：D 日的任一预测、场景与参数仅使用日期 \(<D\) 的记录。

## 4. 模型

### 4.1 预测与场景构造

先用可解释基线预测每个日内时段：

- 负荷：同星期历史日的加权均值；样本不足时退化为最近 7 日的加权均值。
- 光伏：最近同星期/相近日期的加权日内曲线；不采用当天真实光伏。

以历史预测残差构造 \(K\) 个联合场景，保留同一天内 144 时段的相关性：

\[
L_{D,t}^\omega=\max(0,\widehat L_{D,t}+e_{L,t}^\omega),\qquad
P_{D,t}^\omega=\max(0,\widehat P_{D,t}+e_{P,t}^\omega).
\]

推荐 \(K=10\)–20 个最近且季节相近的历史日；另以“仅点预测”的确定性计划作基线。

### 4.2 两阶段日前计划

第一阶段在 0:00 选定 \(g_{D,t}\)，且对所有场景相同。每个场景中允许储能动作、弃电和紧急购电：

\[
g_{D,t}+P^\omega_{D,t}+d^\omega_{D,t}+u^\omega_{D,t}
=L^\omega_{D,t}+c^\omega_{D,t}+s^\omega_{D,t},
\]
\[
E^\omega_{D,t}=E^\omega_{D,t-1}+\eta_cc^\omega_{D,t}-\frac{d^\omega_{D,t}}{\eta_d},
\]

其中 SOC、功率上限沿用 Q1，\(E^\omega_{D,0}\) 取前一天实际结束 SOC。终端增加安全约束 \(E^\omega_{D,144}\ge R_D\)。

目标为

\[
\min\sum_t p_tg_{D,t}
+\frac1K\sum_{\omega\in\Omega_D}\sum_t5p_tu^\omega_{D,t}
+\lambda\,\mathrm{CVaR}_{0.90}\!\left(\sum_t5p_tu^\omega_{D,t}\right).
\]

先令 \(\lambda=0\) 得到期望成本方案；以 \(\lambda>0\) 做风险敏感性。CVaR 可用辅助变量线性化，整体仍为 LP。

### 4.3 实际运行与跨日状态

对每个回测日，固定当天 \(g_{D,t}\)，按实际 \(L_{D,t},P_{D,t}\) 做因果调度：优先用光伏和计划购电，储能在满足 SOC 约束下补偿缺口/吸收剩余，最后才使用 \(u_{D,t}\)。当天末 SOC 传入下一日。终端目标 \(R_D\) 取“下一日早高峰净负荷的历史分位数对应储能量”，并与固定 6000 kWh 的简单目标比较。

## 5. 算法

- 推荐：滚动回测循环（按日） + 每日 `cvxpy` 场景 LP + 实际因果仿真。
- 预测基线：加权历史同星期曲线；备选为只用过去数据的 ExtraTrees/梯度提升分位数预测，只有在基线显著较差时使用。
- 场景降维：保留 10–20 个代表日，避免每一天使用全部历史日而拖慢求解。
- 复杂度：每日变量量约为 \(144\times K\)；全年回测可在分钟级完成。

## 7. 验证

- 时间切分审计：任一 D 日训练数据最大日期必须小于 D。
- 物理检查：逐时段能量平衡、SOC/功率边界、跨日 SOC 连续。
- 比较：点预测确定性 LP vs 场景 LP；报告总成本、紧急购电量/次数、95% 日成本。
- 消融：固定终端 SOC 目标 vs 动态安全储备；不同场景数 \(K\)、风险权重 \(\lambda\)。
- 重点日期：2025.3.20、6.21、9.23、12.21，分别导出题目要求的紧急购电结果。

## 8. 论文要点

- 明确“日前计划”和“实时紧急补救”是不同决策阶段，解释为什么需对紧急电施加 5 倍惩罚。
- 强调联合残差场景保留负荷与光伏的同日相关性，避免独立抽样造成不真实组合。
- 报告成本下降与供电可靠性改善的权衡，不能只给平均成本。
