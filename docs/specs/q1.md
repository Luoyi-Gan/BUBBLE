# C 题 · 小问 1 建模规格

> Codex 起草 → AI 队长确认 → Cursor 实现。确认后在文首改状态为 **已确认** 并填日期。

**状态：** 草稿  
**题目 / 小问：** C 题 Q1：给定日内电价、负荷与光伏预测的日前购电策略  
**队长确认：** —

## 1. 目标

在每天 0:00 已知当天 10 分钟粒度的电价、负荷和光伏预测功率时，确定外网购电与储能充放电计划，使小区供电需求被满足、购电成本最小，且储能 0:00 与 24:00 的电量相同。

成功标准：可复现地生成题目要求的 `result1.xlsx`，所有时段能量平衡、储能边界和首末电量约束均满足。

## 2. 假设与符号

一个时段长度为 \(\Delta=1/6\) h，共 \(T=144\) 个时段。附件中的功率先乘 \(\Delta\) 转为能量。

| 符号 | 含义 | 单位 / 取值范围 |
|---|---|---|
| \(L_t\) | 小区负载能量 | kWh |
| \(P_t\) | 光伏发电可用能量 | kWh |
| \(p_t\) | 外网电价 | 元/kWh |
| \(g_t\) | 计划购电量 | kWh，\(\ge0\) |
| \(c_t,d_t\) | 接入储能的充电、向负载侧的放电量 | kWh，\(\ge0\) |
| \(E_t\) | 时段末储能电量（SOC） | kWh |
| \(s_t\) | 未被利用的光伏/购电弃电量 | kWh，\(\ge0\) |
| \(\eta_c,\eta_d\) | 充电、放电效率 | 暂按 0.9、0.9 |

必要假设：

1. 光伏优先用于负载和充电；不能向外网售电，不能使用的能量计入 \(s_t\)。
2. 在无补贴且 \(\eta_c\eta_d<1\) 的条件下，同时充放电不会改善目标，因此不引入二元变量；实现后须检查 \(c_td_t\) 是否近似为 0。
3. 题中“充放电效率为 90%”暂按充、放电各 90% 处理；需在论文中说明该口径，并做效率敏感性分析。

## 3. 数据

- 来源：`C题/附件/附件1.xlsx`，工作表 `Sheet1`。
- 字段：时间、电价、小区负载、光伏发电预测功率。
- 预处理：将 144 个 10 分钟时段按时间排序；功率乘以 \(1/6\) 转换为 kWh；检查无缺失、非负且首末时段完整。
- 文件放置：Cursor 可将原件复制到 `data/raw/c/`（不提交原始大文件），并在代码中保留来源说明。

## 4. 模型

### 4.1 变量与约束

储能最大功率为 5000 kW，因此每时段充、放电上限为

\[
0\le c_t,d_t\le 5000\Delta=833.3333.
\]

能量平衡和储能递推为

\[
g_t+P_t+d_t=L_t+c_t+s_t,
\]
\[
E_t=E_{t-1}+\eta_c c_t-\frac{d_t}{\eta_d}.
\]

并满足

\[
1200\le E_t\le10800,\qquad E_0=6000,\qquad E_{144}=E_0.
\]

### 4.2 目标

\[
\min\ \sum_{t=1}^{144}p_tg_t.
\]

这是线性规划（LP），用 HiGHS 求解。若出现多解，第二阶段以极小权重最小化弃电或充放电总量，只用于获得稳定、可解释的输出，且不得改变主目标最优值。

## 5. 算法

- 推荐：`cvxpy` 建 LP，优先 `HIGHS`；求解失败时再尝试 `CLARABEL`。
- 实现顺序：数据读取 → 单位转换 → 约束建立 → 求解 → 残差检查 → 导出。
- 备选：`scipy.optimize.linprog(method="highs")`。
- 注意：`00:00+1` 必须作为第 144 个时段结束边界处理，不能误读为下一天新的决策时段。

## 7. 验证

- 逐时段检查能量平衡残差绝对值 \(<10^{-6}\) kWh。
- 检查所有 SOC、充放电量均在边界内，且 \(|E_{144}-E_0|<10^{-6}\) kWh。
- 逻辑检查：低价/光伏富余期倾向充电，高价期倾向放电；异常情况必须解释。
- 灵敏度：\(\eta\in\{0.85,0.90,0.95\}\)、容量上下浮动 10%、最大功率上下浮动 10%。
