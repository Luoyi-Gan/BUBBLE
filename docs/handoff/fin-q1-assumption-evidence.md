**负责人：** FIN

## 一、交付规则

每一条证据必须记录在 `refs/` 的新 Markdown 文件中，并包含：

| 必填项 | 要求 |
|---|---|
| 来源 | 优先同行评审论文、IEC/GB/IEEE 标准、NREL 等官方技术报告；不得以博客、营销页或未核验摘要作为唯一依据 |
| 文献信息 | 作者/机构、题名、年份、DOI 或稳定链接、页码/章节（能取得时） |
| 可用论断 | 用自己的话概括该来源支持什么，不复制长段原文 |
| 适用边界 | 该论断适用于电芯、储能系统 AC 侧，还是微网调度模型；不能越界引用 |
| 论文落点 | 对应“模型假设”“符号说明”或“模型评价”的哪一句 |

引用格式按 GB/T 7714 留下可复用条目。每条参考文献至少由两名队员可访问链接或 PDF 复核。

## 二、四项分任务

### F1 高峰时段与社区规模：仅做附件数据核对，不检索论文

1. 从附件 1 整理三种不同概念，不能混写：
   - 负荷峰：\(L_t\) 最大/高分位时段；
   - 净负荷峰：\(L_t-P_t\) 最大/高分位时段；
   - 电价峰：\(p_t\) 高分位时段。
2. 记录附件中的事实：负荷峰约 09:10、净负荷峰约 17:40、电价峰约 20:40；这些是数据结论，不需要找论文“证明”。
3. 不检索或引用论文来“证明”高峰时段；峰时段、峰数和规模均应由附件 1 的数据直接计算得出。
4. 不推断小区住户数、面积或人口。论文只写“由 MW 级负荷、MW 级光伏和 12 MWh 储能构成的社区微网”，其规模依据题目数据。

**签收产物：** `refs/c_q1_peak_and_scale.md`，含一张三类峰的定义表、计算规则和附件数据位置；不要求参考文献。

### F2 90% 充放电效率：优先解决术语与系统边界

1. 找至少 2 个高质量来源，其中至少 1 个为标准、官方技术报告或同行评审论文，说明往返效率（round-trip efficiency）的定义：完整充放电循环的输出能量/输入能量。
2. 找至少 1 个微网储能调度模型，说明如何将总往返效率拆分为充电效率 \(\eta_c\) 和放电效率 \(\eta_d\)。
3. 对比两种可选口径：
   - 口径 A（推荐待确认）：题给 90% 为总往返效率，\(\eta_c=\eta_d=\sqrt{0.9}\)；
   - 口径 B（敏感性）：充、放电各 90%，总往返效率为 81%。
4. 明确来源的测量边界：电芯、PCS 直流侧或系统交流侧不可混用。

**签收产物：** `refs/c_q1_efficiency.md`，含定义、两种口径的数学后果、推荐表述和 3 条以上可复核来源。

### F3 初始电量 6000 kWh：解释状态而非创造新假设

1. 找 1–2 篇储能日前调度/微网优化研究，支持“初始 SOC 是状态方程初值；日内模型常设置终端 SOC 等于初始 SOC，以避免用期末透支虚假降低成本”。
2. 写清 C 题 Q1 的解释：\(E_0=6000\) kWh，且题目要求 \(E_{24:00}=E_{0:00}\)，故 6000 同时是初值和终值；它不是额定容量、每日重置值或额外目标。
3. 记录对后续小问的边界：Q2–Q4 只将 2025.1.1 0:00 的 6000 kWh 作为全年递推起点，不能直接沿用 Q1 的“每日首末相等”。

**签收产物：** `refs/c_q1_initial_soc.md`，含可直接放入“模型假设”的 80–120 字中文段与至少 2 条来源。

### F4 最低 SOC：区分题给硬约束和不确定性下的运行储备

1. 确认题面硬边界：\(1200\le E_t\le10800\) kWh；其对应额定容量 12000 kWh 的 10%–90% SOC，允许调度容量为 9600 kWh。
2. 找至少 1 条来源支持设置 SOC/放电深度边界以保护电池寿命与运行安全。
3. 论文中不得把文献中的任意“推荐最低 SOC”覆盖题目给定的 1200 kWh。Q1 直接采用 1200 kWh；额外运行储备只留给 Q2–Q4 的预测误差讨论。

**签收产物：** `refs/c_q1_soc_bounds.md`，含硬约束解释、引用和“为什么 Q1 不额外加储备”的说明。
