## 1. 近年真题速览（本科组 ABC）

| 年份 | A 题 | B 题 | C 题 |
|------|------|------|------|
| 2024 | 板凳龙螺线运动学 | **生产过程中的决策问题**（抽检、多阶段决策） | 农作物种植策略（多目标+随机） |
| 2025 | 烟幕弹投放策略（动态优化） | **碳化硅外延层厚度**（光学干涉+拟合） | NIPT 时点与异常判定（医学数据） |

**稳定规律**

- A：机理/几何/动力学，难度高，要会 ODE 或空间优化
- B：开放性强，**统计 + 优化 + 决策** 组合多；不局限于「经管故事」
- C：数据驱动，变量多，竞争大，论文要出彩

## 2. 2026 官方风向（已确认）

1. **赛题 9.10 18:00 发布**（mcm.edu.cn、知网等）
2. **[人工智能工具使用规定（2026 试行）](https://www.mcm.edu.cn/html_cn/node/fef94648f2836ab6cc81586f4c38512b.html)**
   - 可用 AI，但**核心建模与分析须队里主导**

   - 使用 AI 须交 **`AI工具使用详情.pdf`**（工具、环节、提示词、人工核验）
   - 隐瞒/虚假声明/未核实即作核心成果 → **取消评奖**
3. 2026 研讨会强调 **AI 赋能建模**、国产计算软件 — 题面可能更贴近「智能决策」「数据+算法」叙事，但不等于必须深度学习

**对你们**：技用 Cursor 合法且应规范记录；ACCT 负责声明与 PDF；FIN 润色可写进「语言润色」类用途。

## 3. 命题趋势（用于调整备战重心，非猜题）

| 趋势 | 可能体现 | 对应方法 |
|------|----------|----------|
| 真实数据、大规模 | C 题、部分 B 题 | pandas、清洗、回归、集成学习 |
| 不确定性/随机性 | B/C | 随机规划、蒙特卡洛、贝叶斯、灵敏度 |
| 多阶段决策 | B | 动态规划、期望收益、MDP 简化 |
| 质检/抽检/可靠性 | B（2024 已考，可能变体） | 假设检验、OC 曲线、序贯决策 |
| 新能源/材料/光学反演 | B（2025 已考） | 非线性最小二乘、机理+拟合 |
| 低空经济/交通/物流 | B/C | 路径优化、排队、网络流 |
| 医疗/健康数据 | C（2025 已考） | 分类、回归、风险优化 |
| 农业/资源/环境 | C | 多目标优化、随机规划 |
| 碳中和/能源调度 | B/C | 线性/整数规划、多目标 |
| AI/大模型相关背景 | 题面叙事可能出现 | 仍是数学建模，不是调 API |

**命题逻辑**：有时代性的**实际问题** + 72 小时内可建模 + 能区分建模能力（不只看算出一个数）。

## 4. 2026 各题「可能出现」的方向（推测）

### A 题（慎选，除非 30min 试推导能跑通）

| 可能方向 | 建模核心 | 你们风险 |
|----------|----------|----------|
| 刚体/多体运动、轨迹规划 | ODE、几何、非线性优化 | 物理背景重，商科难写 |
| 机器人/无人机路径 | 运动学 + 避障优化 | 与 2025 烟幕弹同类 |
| 工程测量/标定 | 几何 + 最小二乘 | 若偏拟合可考虑 |

### B 题（首选 — 与 `cumcm-b-problem` skill 对齐）

| 可能方向 | 建模核心 | 你们优势 |
|----------|----------|----------|
| **供应链/生产/质检决策** | 0-1 规划、DP、假设检验 | 2024B 同类；FIN 决策叙事 |
| **定价/库存/促销** | 随机需求 + 优化 | FIN 熟悉；ACCT 成本约束 |
| **信贷/风控/抽样** | 统计检验 + 决策阈值 | FIN 主场 |
| **能源/充电/调度** | 整数规划、图论 | 技可编程；故事清晰 |
| **光学/材料/无损检测** | 机理 + 非线性拟合 | 2025B 变体 |
| **服务系统/排队** | 排队论 + 仿真 | 中等难度 |
| **博弈/多方决策** | 纳什、Stackelberg 简化 | 写作要求高 |

### C 题（次选 — 数据好再选）

| 可能方向 | 建模核心 | 注意 |
|----------|----------|------|
| 用户行为/市场分析 | 回归、聚类、预测 | 人多，论文要深 |
| 公共卫生/流行病学 | 时序、SEIR 简化 | 2025 医学相邻 |
| 农产品/电商销量 | 时序 + 优化 | 2024 农业相邻 |
| 评价类（城市/政策） | 熵权、TOPSIS、AHP | 商科好写，创新难 |

## 5. 选题当晚流程（9.10 20:30 前锁定）

1. 三人各读一遍，**技**用 Cursor 填「六要素 + 3 天能否做完」
2. **FIN**：哪个题「决策/不确定性」故事最好写
3. **ACCT**：哪个题约束/表格最清晰
4. **A 题**：20:00 起 30min 试推导，失败则放弃
5. 优先级默认：**B > C（数据齐）> A（仅试通）**
