# 2026 国赛 · AI 工具合规

官方允许使用 AI 工具，但须在支撑材料中**声明**并提交 **`AI工具使用详情.pdf`**。

## 赛前准备

- [ ] 队赛官网下载当年 AI 工具说明模板（若有更新以官网为准）
- [ ] 本队使用的工具清单：Codex、Cursor（Composer / Grok / Sonnet 等具体型号）、FIN / ACCT 是否用免费模型
- [ ] 约定：凡 AI 参与撰写的论文段落、代码、图表，均在 PDF 中可追溯

## 赛中记录（队长维护草稿即可）

每类使用记一条：

| 时间 | 工具 | 用途 | 输入概要 | 输出落点 |
|------|------|------|----------|----------|
| | Codex | 建模规格 q1 | 题目原文 | `docs/specs/q1.md` |
| | Cursor | 实现 q1 | 已确认规格 | `q1/` `output/` |
| | … | | | |

## 提交前

- [ ] `AI工具使用详情.pdf` 已写入支撑材料
- [ ] 论文中按组委会要求标注 AI 辅助部分（若要求正文声明）
- [ ] 不与「未使用 AI」矛盾；不隐瞒 Cursor 生成的代码路径

## 原则

- AI 辅助不替代队长的建模决策与结果责任
- 数字以可复现的 `output/` 为准，不直接采信模型口述数值
