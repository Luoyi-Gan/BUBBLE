# Q1–Q2 论文证据库

复核日期：2026-09-11

本目录是为当前 Q1、Q2 模型单独建立的 reference 包。它同时收录两类证据：

1. **项目内直接证据**：题意映射、模型规格、代码输出、校验文件和结果表；这些材料支持“本题具体用了什么参数、得到什么数字”。
2. **外部方法证据**：同行评议论文、权威教材和实验室/机构报告；这些材料支持“为什么这种建模方式合理、适用边界是什么”。

## 最快使用方法

- 写论文正文前先看 `claim_source_map.md`：按“要写的主张”找最短证据链。
- 需要确认原文位置、能说到什么程度时看 `source_cards.md`。
- 中文参考文献表可从 `citation_ready_gbt7714.md` 复制并按学校模板微调。
- LaTeX / Zotero / JabRef 可导入 `references.bib`。

## 使用原则

- 题给容量、功率、效率、5 倍紧急购电价等数值，应引用赛题原文或附件；外部文献只能解释参数含义，不能替代题目给值。
- Q1 的“90% 为往返效率并作对称拆分”、Q2 的“不售电、正常计划购电无上限”、`K=8`、风险分位候选集合、历史窗口长度等，均属于本项目的建模解释或经验选择。正文必须这样表述，不能写成“文献规定”。
- Q2 当前正式方案是固定 `K=8` 的滚动风险分位方案；动态 K 仅为旧对照。CVaR 也只列作扩展方向，不是当前主模型。
- “相关文献采用过”不等于“本题参数已被验证”。所有引用均在证据卡中给出了迁移边界。
- 本目录提供稳定 DOI、出版社/机构页或开放全文入口，不复制受版权保护的论文全文。

## 当前模型口径摘要

### Q1

144 个 10 分钟时段的确定性线性规划，目标为最小化分时购电费；储能状态连续，首末均为 6000 kWh；题给 90% 按往返效率解释并取对称单程效率；不售电，富余光伏可弃；主模型不设外网购电上限。

### Q2

全年跨日 SOC 连续。每天 0:00 用历史信息生成负荷/PV 预测和联合残差场景，以 `K=8` 个 medoid 场景做两阶段日前计划；实际运行中计划购电量固定，按已观测残差前缀更新场景权重并滚动执行单步控制，不足量以 5 倍电价紧急购电。48 h 下一日价值通过对偶支持割近似，且只影响决策，不计入实际账单。

## 重要边界

本证据库不替代赛题 PDF 与原始附件。当前公开 BUBBLE 副本没有 `C题.pdf` 和附件 1/2 原件，因此正式提交前仍需由团队在原件上补齐题面页码、工作表名、列名和单位；项目内结果数字可由现有 CSV、JSON、XLSX 和审计文件复核。
