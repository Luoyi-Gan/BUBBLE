# AI 队长 · Prompt

队长做最终决策；Codex 出规格、Cursor 写代码。以下场景在**独立对话**中使用，避免与实现线程混用。

## 选题评估（9.10 傍晚）

队伍 1 个 AI 队长 + FIN + ACCT，辅以 Codex / Cursor。题目如下[全文]。

请输出：
1. 三题可行性（能否 3 天内做完）
2. 推荐排序与理由
3. 每题预估小问分工与主要风险
4. 若选 B / C，数据从哪来、预处理量多大

**不要**在此对话里写完整代码；选定后另开 Codex 会话起草规格。

## 规格确认（每个小问一次）

Codex 已给出建模规格如下[粘贴 `docs/specs/qN.md` 或对话摘要]。

请队长确认或修订：
- 模型目标与核心假设是否采纳
- 输入 / 输出 / 约束 / 指标口径
- 算法路线与检验方案
- Cursor 实现优先级与截止时间

确认后回复「规格已确认，可交给 Cursor 实现」，并注明版本号或日期。

## 结果签收（Cursor 跑完后）

`output/` 与 `fig/` 已更新，摘要如下[粘贴关键 CSV 列名与数值]。

请队长判断：
1. 是否与已确认规格一致
2. 有无需要 Codex 再审的逻辑问题
3. 可否写入 `results_summary.md` 供 ACCT / FIN 使用

## 提交前终审

对照 `checklists.md` 与 `results_summary.md`：
- 论文数字 = `output/` = 摘要
- 支撑材料完整（含 AI 工具声明，见 `docs/ai-compliance.md`）
- 选定提交 commit 并备份
