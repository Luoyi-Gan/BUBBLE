2026 年全国大学生数学建模竞赛 C 题支撑材料说明

一、压缩包内容
1. q1 至 q4：四问正式计算所需的完整 Python 程序和结果导出程序；
2. scripts：论文表格导出与数字对账脚本；
3. results：五份按题设模板导出的正式结果工作簿，以及论文数字对账记录；
4. requirements.txt：运行依赖；
5. AI_Tool_Usage_Details.pdf：AI 工具使用声明的支撑说明。

二、运行环境
Python 3.11 或更高版本；安装依赖：
pip install -r requirements.txt

三、题设附件
题设原始附件不随支撑材料重复提交。请将题设附件 1 至附件 5 放入 data/raw/附件/，或将环境变量 CUMCM_C_ATTACH_DIR 指向该目录；随后从项目根目录运行相应 q1 至 q4 目录中的 run_*.py 脚本。程序按原目录结构使用相对路径。

四、结果核验
results/result1.xlsx 至 results/result4-3.xlsx 为论文对应的正式工作簿；results/reconciliation.md 给出已完成的正文数字对账记录。输出区间、预热期和结算口径以论文及对账记录为准。

五、匿名说明
压缩包未包含参赛学校、赛区、队员姓名、账户信息或本地绝对路径。
