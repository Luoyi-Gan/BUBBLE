# 论文本地备份

正式写作源已同步至 `overleaf/`，可将该目录完整上传至 Overleaf，并以 `main.tex` 作为主文件。此处放：

- `outline.md` 章节大纲
- `COMPLETION_PLAN.md`：当前缺口、分工、验收门与交稿清单
- 问题三可粘贴稿：`q3_section.tex`、`q3_problem_analysis.tex`、`q3_abstract_paragraph.tex`
- 问题三可写/必等对照：`q3_write_boundary.md`
- 问题三对账：`q3_reconciliation.md`
- 导出的 PDF 备份（可选，注意体积）
- `overleaf/`：可独立编译的 LaTeX、图表、数据、样式、写作计划及当前 PDF 快照

机理图在 `fig/q3_paper/`。不提交可由 XeLaTeX 重建的 `.aux`、`.log`、`.out` 缓存；`overleaf/main.pdf` 是本次同步后的可审阅快照。

**数字纪律：** 只有同时出现在队长确认的 `results_summary.md` 和 `output/` 中的数值才能替换 `q3_section.tex` 里的宏。文档复核记录中的 Q3 年度成本不得直接抄进正文。
